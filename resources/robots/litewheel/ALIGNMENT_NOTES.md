## 2026-10-15 Litewheel 前向修正（当前约定）

已确认实际前方为原 Base 的 -X。`litewheel.urdf` 和
`litewheel_rl.urdf` 现在使用 +X 向前、+Y 向左、+Z 向上的基座坐标系。
新 Base 相对旧 Base 绕 Z 旋转 180 度，旧 LF/LH/RF/RH 分别改名为
新 RH/RF/LH/LF；连杆名、关节名和父子引用同步更新，声明顺序仍为
LF、LH、RF、RH，每腿为 HAA、HFE、KFE、WHEEL_MOTOR。

保留 CAD 腿部局部坐标和 STL 文件名，各 HAA 安装位姿的 x/y 取反，
yaw 设为 pi。所有 HAA 的局部轴改为 `-1 0 0`，HFE、KFE、轮子的
局部轴改为 `0 -1 0`。因此零位时，换算到新 Base 的 HAA 轴为 +X，
其余关节轴为 +Y。轴翻转使同一物理姿态对应 `q_new = -q_old`，
速度和力矩也取反；限位转换为 `[-upper_old, -lower_old]`。

Base 的视觉、碰撞和惯性 origin 同步绕 Z 旋转 180 度；惯量数值保留在
随之旋转的惯性坐标系中。腿部几何尺寸、局部位姿、质量、惯量以及各关节的
力矩/速度上限保持不变。`md_walk_config.py` 的默认 HFE/KFE 角度同步
改为 -0.762/+1.439，并交换前后足端的 x 目标以保持原有物理站姿。
旧检查点的关节顺序和角度约定不能直接沿用。

验证：两个 URDF 均检查了 17 个连杆、16 个关节的唯一命名、树结构、
LF/LH/RF/RH 声明顺序、零位象限、基座坐标中的关节轴和限位转换。
分别使用零位、默认站姿及 64 组随机关节姿态，对比修正前后的正运动学、
所有视觉/碰撞/惯性坐标变换及世界坐标惯量，误差在 1e-12 容差内；
几何尺寸、质量、力矩和速度上限保持一致。尚未运行动力学仿真。

## 内容对齐

机器人名称为 `dynawheel`，基座为 `Base`；腿顺序为 LF、LH、RF、RH，每腿关节顺序为 HAA、HFE、KFE、WHEEL_MOTOR。连杆依次为 hip、thigh、calf、wheel。左前原 `FL_thigh` 实际对应 hip，原 `FL_thigh1` 对应 thigh；重名关节、大小写和拼写问题随命名统一修复。关节名称 YAML 同步更新。

排版采用两空格缩进、单行属性、参考中的全局材料定义、关节后紧接子连杆的组织方式。新增网格的文件名保持 CAD 导出名称。

HAA 轴为 `1 0 0`；HFE、KFE、轮子轴为 `0 1 0`，所有 joint origin 的 rpy 仍为零。原轴的镜像符号及微小偏斜被统一：HAA 偏斜约 0.0043 度，其余轴偏斜约 0.652 度。此处理假设偏斜是导出误差；若 CAD 存在真实安装倾角，应保留倾角并重新定义关节坐标系。翻转轴方向后，旧导出模型的关节角、速度、力矩符号不能直接沿用。

新 CAD 的关节位置、网格、尺寸和已有惯性参数保留。碰撞仍使用新 CAD 网格，没有套用旧机器人尺寸的简化碰撞体。轮子添加参考的 `dont_collapse="true"` 属性。

## 惯性修复

左前腿四段均包含有效惯性参数，并未发现缺失。实际缺失的是右后髋 `BR_hip`，其质量和六项惯量全部为零。修正后的 `RH_hip` 使用左后髋 `BL_hip` / `LH_hip` 关于 XZ 平面的对称参数：

- 质量：1.0334 kg。
- 质心：`0.034133 -0.02979 0.00034385` m。
- 惯量：ixx=0.00060603，ixy=0.00013482，ixz=-1.4729E-06，iyy=0.00067582，iyz=1.6653E-08，izz=0.00067713 kg m²。

使用 `S=diag(1,-1,1)`，变换 `c'=S c`、`I'=S I S^T`。补值建立在左右髋结构与质量相同的假设上，应以 CAD 重新导出的质量属性为最终依据。
